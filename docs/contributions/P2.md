# P2 - Data Pipeline Contributions

**Day 1**
* Verified programmatic access to ERA5 reanalysis via Copernicus CDS and GFS forecasts via AWS Open Data.
* Established the initial data ingestion architecture and downloaded pilot files for Coastal Karnataka.

**Day 2**
* Engineered the alignment script using `xarray.interp()` to accurately regrid 0.25° GFS forecasts onto the ERA5 observation grid.
* Generated a 14-day aligned pilot dataset (`aligned_pilot.parquet`) to unblock the ML (P3) and Baseline (P6) teams.

**Day 3**
* Scaled the automated pipeline to process the full 122-day 2023 monsoon season across Coastal Karnataka, Maharashtra, and Tamil Nadu.
* Implemented robust error handling to bypass AWS DNS timeouts and corrupted files, successfully delivering the final 6,013,136-row training dataset.
